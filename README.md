# Korean Chicken Franchise Comparison

A bilingual English/Korean student project comparing BBQ, bhc Chicken, and Kyochon Chicken using average annual sales per franchise location for the 2023 base year.

## Metric and caveat
The comparison is franchisee-store average annual sales, not parent-company revenue or profit. Kyochon and bhc values are listed as reported in the cited KFTC statistics; BBQ is marked approximate because it is taken from a secondary report.

## Sources
- [Korea Fair Trade Commission — 2024 Franchise Business Statistics](https://www.ftc.go.kr/www/selectBbsNttView.do?bordCd=3&key=12&nttSn=45987)
- [SkyDaily comparative report](https://www.skyedaily.com/news/news_view.html?ID=281938)
- [Kyochon F&B](https://www.kyochonfnb.com/), [bhc](https://www.bhc.co.kr/), [BBQ](https://www.bbq.co.kr/)
